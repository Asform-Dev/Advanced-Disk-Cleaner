# 🧹 Advanced Disk Cleaner

**Advanced Disk Cleaner** is a modern, fast, and safe disk cleanup utility built exclusively for **Windows**. It helps you locate unnecessary files, preview every result before deletion, and reclaim valuable storage space through an intuitive and user-friendly interface.

Unlike many cleanup tools that automatically remove files, Advanced Disk Cleaner puts **you in complete control**. Every detected file is displayed before deletion, allowing you to decide exactly what should be kept or removed. The application also identifies files located inside potentially important system folders and warns you before deleting them.

Whether you're cleaning your Downloads folder, removing empty files, searching for old images, or freeing up disk space, Advanced Disk Cleaner provides a secure and efficient way to manage your storage.

---

# ✨ Features

- ⚡ Fast recursive folder scanning
- 📂 Scan any folder or drive
- 🔍 Search by file type
  - PNG Images
  - JPG/JPEG Images
  - Python Files
  - C++ Files
  - Virtual Disk Images (VDI)
  - Empty Files
  - All File Types
- 📊 Live storage recovery estimation
- 🛡️ Safe deletion workflow
- ⚠️ Automatic detection of potentially risky folders
- ✅ Individual Keep/Delete selection
- 🔄 Bulk Keep All / Select All actions
- 🎨 Modern desktop interface
- 🌐 Completely offline (no telemetry, no internet connection required)

# 📥 Installation

## Option 1 — Download the Executable (Recommended)

1. Open the **Releases** page.
2. Download the latest release.
3. Extract the ZIP archive if necessary.
4. Launch **Advanced Disk Cleaner.exe**.
5. Start cleaning your storage.

---

## Option 2 — Run From Source

Clone the repository:

```bash
git clone https://github.com/Asform-Dev/Advanced-Disk-Cleaner.git
cd Advanced-Disk-Cleaner
```

Install dependencies:

```bash
pip install python-fasthtml pywebview uvicorn
```

Run the application:

```bash
python app.py
```

Browser mode:

```bash
python app.py --web
```

---

# 🚀 How To Use

1. Launch **Advanced Disk Cleaner**.
2. Select the folder or drive you want to scan.
3. Choose the file types to search for.
4. Click **Scan**.
5. Review every detected file.
6. Choose which files to **Keep** or **Delete**.
7. Click **Delete**.
8. Type **DELETE** to permanently remove the selected files.

Nothing is deleted until you confirm the operation.

---

# 🔒 Safety

Advanced Disk Cleaner was built with safety as a priority.

- Nothing is deleted automatically.
- Every file is shown before deletion.
- Individual files can be marked as Keep.
- Important folders are highlighted with warnings.
- Permanent deletion requires manual confirmation.
- Runs entirely on your computer without uploading any files or data.
